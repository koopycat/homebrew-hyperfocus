# Hyperfocus Cask Tap

Homebrew cask for [Hyperfocus](https://koopycat.github.io/hyperfocus/), a macOS utility that blurs and desaturates background windows so only the active window stays sharp.

## Install

```bash
brew tap koopycat/hyperfocus
brew install --cask hyperfocus
```

The cask is updated per release; bump requests go through PRs to this repository.
